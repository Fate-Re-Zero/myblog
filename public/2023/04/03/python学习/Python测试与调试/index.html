测试最佳实践

  1. 测试文件命名 test_*.py 或 *_test.py
  2. 每个测试只验证一个行为
  3. 用 fixture 管理测试数据，避免重复
  4. 集成测试与单元测试分离
  5. CI 中运行 pytest --cov 和 ruff check

小结

  • 新项目优先 pytest，参数化与 fixture 提高效率
  • breakpoint() 快速断点调试
  • ruff + mypy 保证代码风格与类型安全
  • 测试覆盖核心逻辑，不必追求 100%
