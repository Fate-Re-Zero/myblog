切片 vs 数组 vs Map 选型

场景 推荐
固定长度、值语义 数组（极少）
动态列表、队列 切片
键值查找、计数 Map
并发 Map sync.Map 或 map + Mutex

小结

  • 数组是值类型、定长；切片是引用类型、动态，日常首选
  • append 可能扩容，注意共享底层数组的副作用
  • Map 需初始化后使用，用 v, ok := m[key] 判断 key 是否存在
